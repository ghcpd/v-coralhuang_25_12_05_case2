## ⚠️ Known points & limitations
- Payment integration is a server-side Stripe PaymentIntent placeholder (requires a real test key in STRIPE_SECRET in backend .env). Frontend does not implement Stripe Elements/Checkout by default.
- No external flight/hotel APIs are integrated — search uses the local DB with seeded demo data. Adapters/hooks to external APIs are straightforward to add.
- Security: This is an MVP demo. For production, migrate to PostgreSQL/managed DB, secure environment variables, sanitize inputs more robustly, add rate-limiting, enforce TLS, rotate secrets, etc.
- CI runs backend tests and migrations — local npm may be blocked by PowerShell execution policy in your environment; CI will run within GitHub Actions.
