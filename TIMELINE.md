12-Week Delivery Timeline

Weeks 1-2: Project setup, architecture, and core backend endpoints (auth, bookings).
Weeks 3-4: Integrate Stripe payments, add DB persistence, and implement booking flows.
Weeks 5-6: Implement search and frontend booking UI, responsive design.
Weeks 7-8: Integrate flight/hotel API adapters, caching, and background sync.
Weeks 9-10: Security hardening, automated tests, and performance tuning.
Weeks 11-12: Deployment automation, documentation, QA, and final handoff.

Each week contains checkpoints and demos.
