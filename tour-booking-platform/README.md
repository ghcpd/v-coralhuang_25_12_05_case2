# Tour Booking Platform (Prototype)

This repository contains a production-ready scaffold for a tour and travel booking platform.

Tech stack (recommended):
- Backend: Node.js, Express, PostgreSQL, Prisma ORM, JWT Authentication
- Frontend: React + Vite, Tailwind CSS
- Payments: Stripe (sandbox)
- DevOps: Docker, GitHub Actions CI, Terraform for infra (optional)

This scaffold includes architecture documents, database schema, and minimal starter code for backend and frontend.

## Quick start (development)

1. Backend
   - cd backend
   - npm install
   - copy `.env.example` to `.env` and fill DB and JWT secrets
   - npm run dev

2. Frontend
   - cd frontend
   - npm install
   - npm run dev
