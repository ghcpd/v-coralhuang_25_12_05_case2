## **Optimized Prompt**

You are an experienced software developer with 10 years of expertise in building robust web applications. Your task is to design and develop a comprehensive tour and travel booking platform that meets the following specific requirements:

---

## **1. Core Functionality**

* Users must be able to search for and book tours, flights, and accommodations seamlessly.
* Implement user account functionality that allows users to manage their bookings, preferences, and personal information.

---

## **2. Payment Integration**

* Incorporate a secure payment gateway (e.g., Stripe, PayPal) to facilitate secure transactions and ensure compliance with PCI DSS standards.

---

## **3. User Experience**

* Design a user-friendly interface that enables easy navigation and quick access to various travel options, with an intuitive booking process.

---

## **4. API Integration**

* Integrate with relevant third-party APIs (e.g., flight and hotel availability) to provide real-time data on pricing and availability.

---

## **5. Technical Specifications**

* Ensure the platform is responsive across all devices (desktop, tablet, mobile).
* Build the platform to be secure, utilizing best practices for web security.
* Design for scalability to accommodate a growing number of users without performance degradation.

---

## **Deliverables**

Provide a complete, business-ready platform including all source code, database schemas, and necessary documentation.
The output format should include:

* A zipped directory of the project files.
* A README file detailing the setup process, usage instructions, and API documentation.

---

## **Constraints**

* The project must be completed within 12 weeks.
* All code should be written in a clean, maintainable style, following industry best practices for software development.
