## 🚀 Quick Start Options

### Option 1: Docker Compose (3 commands)
```bash
cd travel-booking-platform
docker-compose up -d
# Done! Access at http://localhost:3000
```

### Option 2: Manual Setup (npm install)
```bash
# Backend
cd backend && npm install && npm run dev

# Frontend (new terminal)
cd frontend && npm install && npm run dev
```

Both options fully functional within 5-10 minutes!

## 💡 Pro Tips

1. **Start with Docker**: Fastest way to get running
2. **Review Architecture**: Understand the design before coding
3. **Check API Docs**: Know all endpoints and their usage
4. **Environment Variables**: Copy `.env.example` and fill in your keys
5. **Database Migrations**: Run `npx prisma migrate dev`
6. **Frontend Components**: Start in `frontend/app/components/`
7. **Add Tests**: Use Jest for backend, Testing Library for frontend
8. **Monitor Logs**: `docker-compose logs -f` is your friend
