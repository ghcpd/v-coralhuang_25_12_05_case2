## ▶️ Quick start (development)

Open PowerShell in project root: tour-booking-platform

Backend:
- cd backend; npm install
- Copy `.env.example` to `.env` and fill `DATABASE_URL`, `JWT_SECRET`, `STRIPE_SECRET_KEY`.
- Initialize DB and Prisma (see `docs/db.md`): 
  - npx prisma migrate dev --name init
  - npx prisma generate
  - node prisma/seed.js
- Run dev server: npm run dev

Frontend:
- cd frontend; npm install; npm run dev
- By default frontend will contact backend at `/api/*` — use proxy or configure baseURL in dev.

Run tests:
- cd backend; npm test

Package (zip deliverable):
- From project root PowerShell: .\scripts\package.ps1 -Output tour-booking-platform.zip
  - This will create `tour-booking-platform.zip` in the project root.
